What's New

The Power Project extension now includes two ways to delete projects:

  • Delete saved groups via right-click context menu
  • Delete projects via the edit project dialog

How to Test - Method 1: Delete Saved Groups

Step 1: Open the Power Project extension sidebar
Step 2: Navigate to the "Saved Groups" tab
Step 3: Right-click on any saved group
Step 4: Select "Delete Project" from the context menu
Step 5: Confirm the deletion in the dialog

How to Test - Method 2: Delete Projects via Edit Dialog

Step 1: Right-click on any project in the projects bar
Step 2: The edit project dialog will open
Step 3: Click the red "Delete This Project" button
Step 4: Confirm the deletion in the dialog

Implementation Details

  • Context menu for saved groups with "Delete Project" option
  • Red "Delete This Project" button in edit project dialog
  • Confirmation dialog shows the project name before deletion
  • Immediate UI update after deletion
  • Deletion persists across browser sessions
  • Modal closes automatically after deletion
