🗑️ Delete Project Feature - Test Guide

✨ Feature Overview

A new "Delete Project" option has been added to the right-click context menu for saved groups/projects in the Power Project Chrome Extension.

  • ✅ Right-click context menu for saved groups
  • ✅ "Delete Project" option in the context menu
  • ✅ Confirmation dialog before deletion
  • ✅ Proper cleanup and UI refresh after deletion

🧪 Testing Instructions

Step-by-Step Testing:

  1. Open the Extension: Click on the Power Project extension icon to open the sidebar
  2. Navigate to Saved Groups: Click on the "Saved Groups" tab (third icon in the tab navigation)
  3. Create Test Groups: If you don't have any saved groups:
    • Go to the "Groups" tab
    • Click the save icon on any tab group
    • Enter a name for the saved group
  4. Right-Click Test: Right-click on any saved group in the "Saved Groups" tab
  5. Verify Context Menu: You should see a context menu with these options:
    • Restore in Current Window
    • Restore in New Window
    • Add to Project
    • Edit Name
    • --- (separator) ---
    • Delete Project
  6. Test Delete: Click "Delete Project"
  7. Confirm Dialog: A confirmation dialog should appear asking: "Are you sure you want to delete the project '[project name]'?"
  8. Test Cancel: Click "Cancel" - the project should remain
  9. Test Confirm: Right-click again, choose "Delete Project", and click "OK" - the project should be deleted
⚠️ Note: The delete action is permanent. Once confirmed, the saved group cannot be recovered unless you have a backup (via the Export feature).

✅ Expected Behavior

  • Context menu appears at mouse position when right-clicking a saved group
  • Context menu disappears when clicking elsewhere
  • Delete option shows a confirmation dialog with the project name
  • Canceling the dialog leaves the project intact
  • Confirming the dialog removes the project from the list immediately
  • The deletion persists across browser restarts

🐛 Troubleshooting

If the feature isn't working as expected:

  1. Reload the Extension: Go to chrome://extensions, find Power Project, and click the reload button
  2. Check Console: Right-click the extension sidebar, choose "Inspect", and check the Console for errors
  3. Clear Storage: If data seems corrupted, you can reset by clearing extension storage (be sure to export first!)
