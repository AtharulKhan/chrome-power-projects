🔍 Search Feature Details

Saved Groups Search

Location: Saved Groups tab header

Features:

  • Always visible search input when on Saved Groups tab
  • Searches through:
    • Group names
    • Tab titles within groups
    • Tab URLs within groups
  • Shows "No saved groups match your search" when no results
// Search implementation
if (this.savedGroupsSearchQuery) {
  filteredGroups = this.savedGroups.filter((group) => {
    // Search in group name
    if (group.name.toLowerCase().includes(this.savedGroupsSearchQuery)) {
      return true;
    }
    // Search in tab titles and URLs
    return group.tabs.some(
      (tab) =>
        tab.title.toLowerCase().includes(this.savedGroupsSearchQuery) ||
        tab.url.toLowerCase().includes(this.savedGroupsSearchQuery)
    );
  });
}

Projects Search

Location: Projects bar (bottom navigation)

Features:

  • Click search icon to toggle search input
  • Search input appears inline with clean animation
  • Searches through project names
  • Shows "No matching projects" when no results
// Toggle search visibility
toggleProjectSearch() {
  const searchContainer = document.getElementById("projects-search-container");
  const searchInput = document.getElementById("projects-search");
  
  this.projectsSearchVisible = !this.projectsSearchVisible;
  
  if (this.projectsSearchVisible) {
    searchContainer.style.display = "flex";
    searchInput.focus();
  } else {
    searchContainer.style.display = "none";
    searchInput.value = "";
    this.projectsSearchQuery = "";
    this.renderProjects();
  }
}

☁️ Cross-Device Sync Details

How Browser Sync Works:

  • Automatic: No configuration needed - just sign into Chrome
  • Real-time: Changes sync within seconds across devices
  • Secure: Data is encrypted and tied to your Google account
  • What syncs:
    • All saved tab groups
    • All projects
    • Project configurations and tab arrangements

Technical Implementation:

// Before (local storage only)
await chrome.storage.local.get("savedGroups");
await chrome.storage.local.set({ savedGroups: this.savedGroups });

// After (synced across devices)
await chrome.storage.sync.get("savedGroups");
await chrome.storage.sync.set({ savedGroups: this.savedGroups });

Storage Limits:

  • Total sync storage: 100KB
  • Per-item limit: 8KB
  • Max items: 512

Note: These limits are sufficient for hundreds of saved groups and projects

🎯 Usage Instructions

To use the search features:

  1. For Saved Groups: Click on the "Saved Groups" tab and start typing in the search box
  2. For Projects: Click the search icon in the projects bar, then type in the search box that appears

To enable sync:

  1. Sign in to Chrome with your Google account
  2. Enable Chrome Sync in settings (usually enabled by default)
  3. Install the Power-Project extension on all your devices
  4. Your saved groups and projects will automatically sync!
