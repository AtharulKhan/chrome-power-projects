🎯 Where to Find Export/Import Buttons

📍 Location 1: Settings Modal

Step 1: Look at the header of the Power Project sidebar

Step 2: Click the ⚙️ Settings button (rightmost icon in header)

Step 3: In the Settings modal that opens, you'll see:

Export Backup
Import Backup

📍 Location 2: Project Manager Modal

Step 1: Look at the bottom of the sidebar for the "Projects" bar

Step 2: Click the ⚙️ Manage Projects button

Step 3: In the Project Manager modal header, next to the search bar, you'll see:

Two icon buttons:
  • 📥 Import Backup button
  • 📄 Export Backup button

⚠️ Important: Reload the Extension

If you don't see these buttons:

  1. Go to chrome://extensions/
  2. Find "Power-Project" extension
  3. Click the refresh/reload icon on the extension card
  4. Open the extension again

🔄 About Chrome Sync

Chrome Sync is already working in your extension! Here's what you need to know:

  • ✅ Data is stored using chrome.storage.sync
  • ✅ It uses your Google account that's signed into Chrome
  • ✅ No separate email setup needed
  • ✅ Data syncs automatically when you sign into Chrome on another device

To Enable Sync:

  1. Open Chrome Settings: chrome://settings/
  2. Click "You and Google" → "Sync and Google services"
  3. Turn on Sync
  4. Make sure "Extensions" is checked in sync settings

📋 What Gets Exported/Imported?

The backup file includes BOTH:

  • ✅ All your Projects
  • ✅ All your Saved Groups

File format: power-project-backup-YYYY-MM-DD.json
